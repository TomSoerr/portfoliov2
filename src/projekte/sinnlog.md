# Sinnlog Tagebuch und Habit tracker 

*Februar 2026*

Vor über 2 Jahren kam ich auf die Idee täglich Tagebuch zu schreiben. Wie sich das als angehender Informatiker so gehört natürlich digital. Über die Zeit verwandelte sich das tägliche Schreiben von Markdown, über eine SQLite Datenbank dann hin zu dieser App. Mir war es wichtig wahr/falsch und numerische Werte für jeden Tag zu sammeln, um Muster zu erkennen. Die App ermöglicht dies, und es ganz einfach ein neuer Eintrag erstellt und dann auf einem Dashboard die Trends beobachtet werden. Ein Setup Prozess gibt es leider noch nicht.

## Funktionen 

- Verschlüsselung mit AGE
- Speichern von wahr/falsch Werten pro Tag
- Speichern von numerischen Werten pro Tag
- Speichern von Fließtext pro Tag
- Step Plot zum vergleichen eines wahr/falsch Wertes mit dem Wohlbefinden
- Errechnung des Wohlbefindens anhand von Gewichten der wahr/falsch Werte und der numerischen Werte
